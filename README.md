# Creator Hub

## 📌 Project Overview

Creator Hub is a web-based platform designed to help creators manage their profile, projects, achievements, and explore new opportunities in one place.

The system provides a simple and user-friendly interface where users can register, login, create their profile, manage projects, view achievements, and explore available opportunities.

---

## 🎯 Objectives

- To provide a centralized platform for creators.
- To allow users to register and login securely.
- To manage creator profile information.
- To add and manage projects.
- To showcase achievements.
- To explore different opportunities.
- To store user information in a database.
- To connect the frontend with a backend API.
